# Gambler
Hello and welcome to the Gambler.  A health utility assessment program.
This program contains multiple health utility assessments to acquire patient's preferences in the form of health utilities.
##Please read the installation guide!
You can find in docs/install.rst and it will guide in installing the files

## Getting started
Once installed used the root of the application to start.  For instance, if your url for the folder is the following:
wwww.mywebsite.com  <- Go to the url and start there
wwww.mywebsite.com/gambler/   <- Go to the url and start there

There it will direct your application.

For setting up your own Gambler, go to /gamblersetup For instance, if your url for the folder is the following:
wwww. mywebsite. com
wwww. mywebsite. com/gamblersetup <- Go to the url and start there
wwww. mywebsite. com/gambler/   
wwww. mywebsite. com/gambler/gamblersetup  <- Go to the url and start there

Happy trails and I wish you luck.
